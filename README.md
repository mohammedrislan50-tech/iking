# Cricket Score Pro

Free single-file HTML/CSS/JavaScript cricket scoring dashboard.

## Run on your phone
Open `index.html` in a browser, or upload this repository to GitHub and enable GitHub Pages.

## Publish with GitHub Pages
1. Create a repository on GitHub (for example `cricket-score-pro`).
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then Save.
6. Wait a little, then open `https://YOUR-USERNAME.github.io/cricket-score-pro/`.

## Included
- Responsive mobile-first score control panel
- Manual scoring, wickets, extras, undo, innings reset/next innings
- Match setup and information
- Player list and officials fields
- Statistics and recent delivery history
- 19 overlay previews and a separate preview window
- Browser-local save and JSON backup export/import

## Important limitations
This is a front-end starter project. It does not include a server, multi-device live sync, ball-by-ball batter/bowler scorecards, automatic OBS integration, or permanent image uploads. Browser-local data stays on that browser/device. Do not enter sensitive information.
